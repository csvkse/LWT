# 原生常驻守护服务示例 (Native Resident Demo)

本示例演示如何使用 LinuxWebTool 的 `Native` 运行时直接托管无需外部语言运行时或编译器的预编译二进制程序。

## 特性
- **零外部运行时依赖**：直接以宿主操作系统进程树方式拉起已编译程序 (Go / Rust / C / C++)；
- **结构化 argv 参数**：使用清单中的 `arguments` 声明固定命令行参数，杜绝 shell 注入；
- **可观察生命周期**：实时采集标准输出与标准错误流至环形缓冲区，支持进程自愈与崩溃雪崩熔断。

## 部署说明
将对应平台的二进制可执行程序放置于 `bin/daemon` (在 Windows 下为 `bin/daemon.exe`)，即可在控制台中启动与管理。
