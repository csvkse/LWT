快速连接与客户端配置指南 (SOCKS5 / HTTP 双模支持)

1. 通过 cURL 验证 SOCKS5 代理连通性 (本地 DNS 解析模式)：

curl -x socks5://127.0.0.1:18080 http://127.0.0.1:5270/health

2. 浏览器与远程域名代解推荐协议 (socks5h 模式，内置 LRU 高速缓存)：

curl -x socks5h://127.0.0.1:18080 http://127.0.0.1:5270/health

3. HTTP / HTTPS 正向代理模式 (RFC 9110 CONNECT 隧道)：

curl -x http://127.0.0.1:18080 http://127.0.0.1:5270/health

4. 为 Git 配置专用代理 (支持 socks5:// 或 http://)：

git config --global http.proxy socks5://127.0.0.1:18080

5. 环境变量导出配置（支持 Bash / Zsh 终端）：

export ALL_PROXY=socks5://127.0.0.1:18080
💡 提示：本微服务已升级为【SOCKS5 / HTTP 单端口双模自适应代理网关】，首字节毫秒级自适应嗅探（RFC 1928 / RFC 9110），内置 Stale-While-Revalidate 异步预刷新 LRU DNS 缓存池与 Singleflight 并发请求合并，TCP_NODELAY 极速直连并杜绝半关闭僵尸连接泄露。
