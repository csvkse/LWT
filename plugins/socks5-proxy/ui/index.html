来源快捷预设:
在 TCP 握手前短路阻断未授权客户端 IP 连接，零资源占用防护网络端口扫描探测。
🎯 维度三：允许访问目标网段 (标准 CIDR) 与域名过滤
出站快捷预设:
严格采用标准 CIDR 掩码位校验。支持输入容错（如 10. 自动补齐为 10.0.0.0/8）。
支持通配符与正则表达式。放行域名仍需进行 Anti-DNS-Rebinding 二次 IP 校验防重绑定穿透。

快速连接与客户端配置指南

1. 通过 cURL 命令验证内网代理连通性：

curl -x socks5://127.0.0.1:18080 http://127.0.0.1:5270/health

2. 为 Git 配置内网专用 SOCKS5 代理：

git config --global http.proxy socks5://127.0.0.1:18080

3. 环境变量导出配置（支持 Bash / Zsh 终端）：

export ALL_PROXY=socks5://127.0.0.1:18080
💡 提示：本微服务采用 Go 原生 JIT 增量编译模式运行，策略保存后自动平滑重启，端口毫秒级恢复无悬挂。
