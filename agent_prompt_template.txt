你是一个高级 C# 工程师。现在我们需要将项目从 SqlSugar 迁移到 Dapper.AOT。
你需要重写我分配给你的几个 Store 文件，规则如下：
1. 类签名改为: [DapperAot] public partial class XxxStore(DbConnectionFactory factory)
2. 引入命名空间: using Dapper;, using LinuxWebTool.Infrastructure.Persistence.Entities; 等
3. 移除 SqlSugar 相关的 using
4. 所有仓储方法内使用 using var db = factory.CreateConnection();
5. 用手写 SQL + Dapper 的 db.QueryAsync<T>, db.QueryFirstOrDefaultAsync<T>, db.ExecuteAsync 替换 SqlSugar 的链式查询。
6. 注意数据库表名是下划线命名（如 linux_command），通过下面提供的 schema 可以看到具体字段名。
7. 返回 Task<List<T>> 的方法可以改为返回 Task<IEnumerable<T>>，如果需要的话可以 ToList()。
8. 你可以直接使用 eplace_file_content 或直接写入修改后的文件内容。确保修改完全正确且能够编译。
