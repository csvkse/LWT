# Windows 终端与文件目录联动实施方案

## 目标与范围

参考 Vue WebTool 的盘符目录浏览和 AITool bridges 的原生终端设计，在现有 .NET 应用内完成 Windows 支持。保留当前未提交的后台会话改动，不引入 Node 运行时。范围确认（2026-10-02）：仅要求软件运行期间与浏览器页面解耦，浏览器断线续跑沿用现有会话管理器和 ConPTY，无需安装 tmux 替代工具。不实施跨软件或系统重启恢复，不新增独立终端宿主。

## 实施顺序

1. 文件路径：后端按运行系统处理路径。Windows 支持盘符绝对路径与 UNC 共享路径，界面统一使用正斜杠；`/` 作为盘符列表入口。盘符和共享根目录不可删除、重命名，程序数据目录保护在 Windows 同样生效。拒绝相对盘符路径、设备路径、ADS 和控制字符。
2. 文件页面：盘符根目录及 UNC 根目录的面包屑、父目录导航、新建与上传拼接正确；目录加载成功后再更新导航。终端当前目录可跳回 Windows 文件管理器。
3. ConPTY：先用聚焦测试复现现有实现的问题，再修复进程命令行转义、Unicode 环境传递、能力判断、空闲/退出状态和句柄生命周期。优先使用原生 ConPTY，创建失败保留明确的管道回退。核对 PowerShell 输入模式与 xterm.js 的兼容性。
4. 验收：Windows 真实会话验证中文及空格目录、输入、Ctrl-C 保留 shell、窗口尺寸、终端目录报告、同 PID 断线接回与未使用会话清理；文件 API 验证盘符入口、根目录保护、数据目录保护和 CRUD。前端门禁与相关 lint；涉及原生互操作时验证 Windows Native AOT 发布。Linux 路径及原有后台会话测试保持通过。
5. 文档：README 更新 Windows 能力和运行限制，记录实际验收证据。每项以当前运行结果为准，未运行的网络共享访问不写成已验证。

## 参考设计的取舍

- 借鉴盘符根目录、操作系统原生路径归一化、默认 shell 探测、OSC 7 目录事件和原生终端优先策略。
- 保留当前流式 OSC 解析与目录访问复验，不复制单输出块正则解析。
- 保留当前后台会话生命周期，不复制固定三分钟后终止已使用会话的策略。
- 管道模式的 Ctrl-C 不用终止整个 shell 来模拟正常中断；页面应明确说明受限能力。

## 实施记录

- 已实施：Windows 盘符入口、原生路径与 UNC 路径处理、根目录和数据目录保护、文件页面与目录选择器面包屑、Windows 终端反向目录入口。
- 已实施：启用 ConPTY，修复启动标准句柄、命令行 Unicode 转义与环境块，补齐退出码、自然退出输出结束、资源释放及原生能力展示。
- 已实施：xterm 焦点通知及设备/光标响应不再作为用户输入清空目录或保留空会话。

## 验收记录（2026-10-02）

- Windows 架构测试 60 项、集成测试 18 项通过。包含真实 ConPTY 中文参数与环境、退出码和输出 EOF、交互输入、窗口尺寸、Ctrl-C 中断任务保留 shell、同 PID 重新附着；文件 API 包含盘符列表、中文文件 CRUD 和数据目录保护。
- 前端架构门禁及 TerminalView、FilesView、FilePicker、filePaths 的 ESLint 通过。全量 ESLint 有其他页面既有 10 个错误、5 个警告，未扩大修改范围。
- Windows Native AOT 发布成功，实际发布程序在本机启动，浏览器确认完整交互模式、中文输出及当前目录报告。当前工具环境未提供 OS 属性，发布时显式传入 `-p:OS=Windows_NT`；Quartz 仍有既有裁剪警告。
- Linux Alpine Native AOT 镜像重新构建成功；真实容器验证 PTY、尺寸调整、Ctrl-C、top 全屏、中文与空格目录及文件 API、60 秒断线续跑、同 PID 续接、有界回放和未使用终端清理均通过。
- 续验：Windows AOT 浏览器中，从文件目录打开终端，再点击“打开当前目录”，成功回到同一路径并显示实际文件列表。此前浏览器自动化失联的原因仍未确定，本次恢复后验收通过。
- 续验：此前独立探针初始目录超时来自测试路径重复转义、与规范化报告不相等。中文输出包含 PowerShell 的颜色和光标可见性 CSI 序列，探针去除 CSI 后比较完整结果行；不把回显命令当执行结果。已加入可重复执行的 `scripts/verify-windows-terminal.mjs`。
- Windows Native AOT 独立探针通过：真实 ConPTY、中文执行结果、焦点通知保留目录且不标记用户输入、同 PID 重新附着和实际文件 API。探针通过环境变量接收临时测试凭据与目录，不保存密码。
- UNC 已验证路径处理与根目录边界，未连接真实网络共享。跨软件、容器或系统重启恢复不在实施范围，原独立会话宿主阶段已移除。
