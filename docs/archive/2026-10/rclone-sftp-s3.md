# SFTP / S3 挂载配置

磁盘挂载页可选择 SFTP 或 S3。两者通过 rclone FUSE 挂载为容器内目录，需要 Linux 宿主机提供 `/dev/fuse` 和挂载权限；部署命令见 README。

## SFTP

- 填写主机、端口、用户名、远端目录及本地挂载点。留空远端目录表示服务器根目录。
- 认证可使用密码，或将未加密的私钥文件放到容器可访问路径后填写绝对路径。当前界面不支持私钥口令；私钥文件由部署者管理，不会复制进应用数据库。
- 必须填写服务器完整 SSH 主机公钥，格式为 `ssh-ed25519 AAAA...` 或 `ecdsa-... AAAA...`。从可信渠道核对公钥后再填写；服务端换钥时需先卸载并更新。应用将其写入专用 `known_hosts` 文件交给 rclone 校验，不接受未经核对的主机密钥。

## S3

- 填写存储桶、Access Key ID、Secret Access Key、本地挂载点；可选桶内前缀。
- AWS S3 不填自定义端点，填写区域。S3 兼容服务填写 HTTPS 端点，可按服务要求填写区域。
- 当前使用静态密钥，不支持运行时 IAM 角色或临时令牌。建议给密钥限定目标桶和前缀所需的最小权限。
- 对象存储不具备完整 POSIX 文件系统语义；频繁原地修改文件、数据库文件和依赖原子重命名的程序不适合直接写入挂载目录。

## 健康与缓存

应用每 30 秒以独立 rclone 命令直接列取远端目录，并在独立进程中读取本地挂载目录。远端故障或认证失败时不会自动重挂；远端正常而本地连续三次失败时，尝试正常卸载并重挂。手动卸载会抑制本次进程内的自动挂载。
S3 的远端检查会产生 `ListObjects` 类 API 请求；大量挂载点可能带来额外请求费用。

每个配置使用独立的 `data/rclone-config/<id>.conf` 和 `data/rclone-cache/<id>`。配置文件在 Linux 上以 600 权限创建；写缓存不会在删除配置时自动清除。卸载或删除前先确认上传完成。健康检查证明目录可读取，不承诺写入权限或服务端完整 POSIX 行为。

参考：[rclone SFTP](https://rclone.org/sftp/)、[rclone S3](https://rclone.org/s3/)、[rclone mount](https://rclone.org/commands/rclone_mount/)。
