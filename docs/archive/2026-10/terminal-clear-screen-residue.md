# 终端清屏后顶部残留

## 问题与复现

2026-10-02，在部署的 Linux 原生 PTY 终端中验证：运行 `top`，退出回到 shell 后，点击快捷按钮“清理屏幕”，顶部仍显示 `top` 的标题和任务统计两行。顶部“清屏”按钮可以消除这些残留。

## 实际证据

- 快捷按钮通过 WebSocket 发送 `clear\n`，命令正常执行。
- 返回的清屏控制序列为 `ESC[H ESC[J`，即光标归位并清除当前屏幕，没有清除滚动历史的 `ESC[3J`。
- 复现时浏览器 `.xterm-viewport` 的 `clientHeight` 为 624、`scrollHeight` 为 661、`scrollTop` 为 0，存在滚动历史且视口停在顶部。
- 顶部两行进入了滚动历史，因此清除当前屏幕后仍能看到；这次复现不涉及重新连接或后台历史回放。

## 处理方案

顶部“清屏”和快捷区“清理屏幕”统一调用 `clearOutput()`，使用 xterm 的 `clear()` 清除当前显示和滚动历史，保留当前光标所在行，并恢复输入焦点。

Linux 和 Windows 快捷指令列表均移除清屏命令，快捷区提供独立的前端清屏按钮，不再向 shell 发送 `clear` 或 `cls`，也无需 WebSocket 连接可用。

该操作只影响当前浏览器显示，不结束进程、不清除后端输出缓冲。重新建立页面终端并回放后台历史时，旧输出仍可能出现。手动输入 `clear` 或 `cls` 仍遵循服务器对应命令的行为。正在运行的 TUI 也可以通过后续输出重新绘制画面。

## 验证范围

部署页面已实际验证原问题及顶部前端清屏的效果。修改后两个按钮共用同一函数；本次静态检查不等同于新版页面已经部署并完成浏览器回归。
